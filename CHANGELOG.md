# Changelog

All notable changes to ThemePilot are documented in this file.

## [0.1.0]
- Initial release with the **IntelliJ IDEA Collection**:
  - `ThemePilot: IDEA Dark (New UI)` with bottom active tab bar, semantic highlighting, italic static fields/constants, inlay hint pills, and crisp `#1E1F22` / `#2B2D30` chrome.
  - `ThemePilot: IDEA Darcula (Classic)`
  - `ThemePilot: IDEA Light`
  - `ThemePilot: IDEA Icons` (32 minimalist IntelliJ New UI file & folder icons with blue source roots, green test roots, purple config/resources, and muted build folders).
- Bundled official SIL OFL 1.1 **JetBrains Mono** fonts (`Regular`, `Italic`, `Bold`, `BoldItalic`) for 1-click offline installation.
- Added `ThemePilot: Apply Full IntelliJ New UI Look & Feel`, `ThemePilot: Apply IntelliJ Font & Ligatures (JetBrains Mono)`, `ThemePilot: Switch Theme`, and `ThemePilot: Reset IntelliJ Look & Feel Settings` commands.
