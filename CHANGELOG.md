# Changelog

All notable changes to ThemePilot are documented in this file.

## [0.1.0]
- Initial release with the **IntelliJ IDEA Collection**:
  - `ThemePilot: IDEA Dark (New UI)`
  - `ThemePilot: IDEA Darcula (Classic)`
  - `ThemePilot: IDEA Light`
- Added `ThemePilot: Apply IntelliJ Font & Ligatures (JetBrains Mono)`, `ThemePilot: Reset Editor Font Settings`, and `ThemePilot: Switch Theme` commands.
